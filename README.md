# C++ Task Manager

A simple command-line task manager written in C++.

This is my first C++ project using object-oriented programming, file persistence, Git and GitHub.

## Features

- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed
- Save tasks to a local file
- Load saved tasks automatically
- Show task statistics
- Basic input validation

## Project Structure

- `main.cpp` - Program entry and menu
- `Task.h / Task.cpp` - Defines a single task and its completion status
- `TaskManager.h / TaskManager.cpp` - Manages tasks and file persistence
